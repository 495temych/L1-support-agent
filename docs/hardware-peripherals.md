# Hardware Peripherals — Device Not Detected

**Applies to:** External monitors, docking stations, keyboards, mice, USB peripherals

**Reported symptoms:** External monitor not detected when laptop is docked, keyboard/mouse unresponsive despite being connected, USB devices not recognized by the system.

**Known causes on record:**
- Faulty or loose cable/dock connection
- Docking station firmware outdated or failing
- Peripheral hardware failure (device itself has failed)
- USB port failure on the laptop

**Standard checks:** cable/connection seating, testing the peripheral on a different port or docking station, checking Device Manager for driver errors vs. no device detected at all.

**Notes:** If the device isn't detected at all in Device Manager (not even as an unrecognized device), this is a physical hardware issue. There is no software-side fix — replacement or physical inspection of the dock/cable/peripheral is required. Do not attempt remote troubleshooting beyond the standard checks above.
